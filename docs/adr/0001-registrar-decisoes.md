# ADR-0001 — Registrar decisões de arquitetura

- **Status:** aceito
- **Data:** 2026-10-07

## Contexto

O projeto vai tomar decisões com consequências duradouras: pagamentos, formato de dados e URLs impressas em peças físicas.

## Decisão

Toda decisão relevante será registrada em `docs/adr/NNNN-titulo.md`, com os campos contexto, decisão e consequências. Um ADR nunca é apagado; quando a decisão muda, um novo ADR o substitui.

## Consequências

O histórico do porquê fica versionado junto do código.
